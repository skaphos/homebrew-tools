# homebrew-tools

Homebrew tap for Skaphos command-line tools.

| Cask | Source |
| --- | --- |
| `repokeeper` | [skaphos/repokeeper](https://github.com/skaphos/repokeeper) |
| `sting` | [skaphos/sting](https://github.com/skaphos/sting) |

## Use the tap

```bash
brew install skaphos/tools/repokeeper
brew install skaphos/tools/sting
```

## How casks are published

The casks in `Casks/` are generated by GoReleaser in each tool's release workflow and pushed
directly to `main`. Do not edit them by hand: the next release overwrites them. Change the
`homebrew_casks` section of the tool's `.goreleaser.yaml` instead.

The macOS binaries are Developer ID signed and notarized, so the casks carry no Gatekeeper
workaround. Each tool's release workflow fails if the signing credentials are missing.

`Tap CI` runs `brew style` and `brew audit --strict --online` on every push and pull request.
Because releases push straight to `main`, a failure there reports a problem after publication
rather than blocking it. Fix the cause in the tool's GoReleaser config.

`Formula/` is reserved for formulae built from source; none exist today.

## Local validation

```bash
brew style Casks/*.rb
brew audit --cask --strict --online skaphos/tools/<cask-token>
```
